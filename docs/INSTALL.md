# Kurulum

1. `Warext-Studios-Konu-Guncellik-Sistemi-1.0.0.zip` dosyasını indirin.
2. XenForo ACP içinde Add-ons bölümüne girin.
3. Install/upgrade from archive alanından ZIP dosyasını yükleyin.
4. Warext Studios - Konu Güncellik Sistemi eklentisini kurun.
5. Options bölümünden genel sistemi etkinleştirin.
6. Nodes > Forums bölümünden kullanılacak forumları açın.
7. Kullanıcı grubu izinlerini yapılandırın.

## Güncelleme

Alpha sürümlerinden 1.0.0 sürümüne yükseltme veri kaybetmeden `Setup.php` upgrade adımıyla yapılır.

## Kaldırma

Standart XenForo eklenti kaldırma işlemi özel tabloları ve forum alanlarını temizler.
